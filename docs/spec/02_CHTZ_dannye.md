# ЧТЗ-02. Данные

Основание: общее ТЗ, разделы 7, 10. Зависимости: ЧТЗ-01.

## 1. Цель

Загрузить армянские наборы живой и синтезированной речи, привести их к единому формату и построить манифест с разбиением по дикторам без утечек между частями.

## 2. Объём работ

Входит:

- загрузчик датасета Hy-Generated (`ErikMkrtchyan/Hy-Generated-audio-data-with-cv20.0`, Hugging Face): живая речь Common Voice и синтез F5-TTS;
- генератор дополнительного синтеза вторым генератором (MMS-TTS) для проверки обобщения;
- приведение звука к единому формату;
- манифест и разбиение;
- CLI и тесты.

Не входит: телефонный канал (ЧТЗ-03), признаки (ЧТЗ-04).

## 3. Функциональные требования

**FR-01. Загрузка Hy-Generated.** `voiceguard.data.hygen.download(dest: Path) -> Path`. Агент изучает карточку датасета, определяет поля (путь к звуку, метка real/synthetic, идентификатор диктора или голоса, текст, часть train/test/eval) и описывает соответствие полей в `data/README.md`. Лицензию датасета также фиксирует в `data/README.md`.

**FR-02. Второй генератор синтеза.** `voiceguard.data.synth_mms.generate(texts: list[str], out_dir: Path, n: int, seed: int) -> list[Path]`. Модель — `facebook/mms-tts-hye` (восточноармянский), если она существует; иначе `facebook/mms-tts-hyw` с пометкой в README. Тексты берутся из текстов Common Voice той части, которая попадает в тест. Объём по умолчанию — 1000 фраз. Если модель недоступна, функция завершается с понятной ошибкой, и этап продолжается без второго генератора (с пометкой в отчёте).

**FR-03. Нормализация.** Все клипы сохраняются в `data/processed/{clip_id}.flac`: моно, 16 кГц, float → PCM16, пиковая нормализация до −1 dBFS, обрезка тишины по краям (порог −40 dBFS). Клипы короче 2 с после обрезки исключаются и учитываются в статистике.

**FR-04. Манифест.** `data/manifest.parquet`, одна строка на клип:

| Поле | Тип | Описание |
|---|---|---|
| `clip_id` | str | Уникальный идентификатор |
| `path` | str | Путь к нормализованному файлу |
| `label` | str | `live` или `spoof` |
| `generator` | str | `none`, `f5tts`, `mms` |
| `speaker_id` | str | Диктор (для live — client_id Common Voice; для spoof — идентификатор голоса или референсного диктора, если он известен) |
| `split` | str | `calib`, `train`, `test` |
| `duration_s` | float | Длительность после обрезки |
| `text` | str | Текст, если есть |
| `source` | str | Исходный датасет |

**FR-05. Разбиение.** Доли по умолчанию: `calib` 30%, `train` 40%, `test` 30% дикторов (не клипов). Правила:

- ни один `speaker_id` не встречается в двух частях;
- синтез, сделанный с голосом референсного диктора, попадает в ту же часть, что и этот диктор (если связь известна из метаданных);
- генератор `mms` целиком относится к `test` (невиданный генератор);
- `calib` используется только для эталона живой речи (ЧТЗ-05) и калибровки (ЧТЗ-08); на нём ничего не обучается;
- если в метаданных синтеза нет идентификатора голоса, разбиение синтеза делается по тексту, и это ограничение записывается в `data/README.md`.

**FR-06. CLI.** `python -m voiceguard.data build [--limit N] [--no-mms]` выполняет FR-01…FR-05. `--limit` ограничивает число клипов каждого класса для быстрых прогонов.

**FR-07. Итератор.** `voiceguard.data.iter_clips(split: str, label: str | None = None, generator: str | None = None, sr: int = 16000) -> Iterator[AudioClip]` читает клипы из манифеста с ресэмплингом до `sr` (`librosa.resample`, `res_type="soxr_hq"`).

**FR-08. Статистика.** `python -m voiceguard.data stats` печатает и сохраняет в `data/stats.json`: число клипов, дикторов и часов речи по `label × generator × split`, число исключённых клипов по причинам.

## 4. Нефункциональные требования

- Повторный запуск `build` не скачивает уже загруженное и не пересчитывает готовые файлы (кэш по хешу источника).
- Полная сборка с `--limit 200` укладывается в 15 минут на 4 ядрах CPU без GPU (без учёта скачивания).

## 5. Критерии приёмки

- **AC-01.** `python -m voiceguard.data build --limit 200 --no-mms` создаёт манифест; `stats` показывает оба класса во всех трёх частях.
- **AC-02.** Тест: пересечение множеств `speaker_id` между частями пустое.
- **AC-03.** Тест: все файлы из манифеста существуют, моно, 16 кГц, длительность ≥ 2 с.
- **AC-04.** `data/README.md` содержит соответствие полей, лицензии источников и известные ограничения разбиения.
- **AC-05.** Модульные тесты работают на фикстуре из 6 синтетических клипов без сети.

## 6. Указания агенту

- Не хранить исходные большие архивы после распаковки, если их можно скачать повторно (флаг `--keep-raw` для обратного).
- Любые предположения о смысле полей датасета записывать в `data/README.md`.
