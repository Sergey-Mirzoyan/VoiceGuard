# ЧТЗ-11. Панель (Streamlit)

Основание: общее ТЗ, разделы 3, 12. Зависимости: ЧТЗ-09 (для живого режима — также ЧТЗ-10).

## 1. Цель

Визуальная часть демонстрации: как система «думает» во время звонка, а также анализ загруженного файла для экспертов и инвесторов.

## 2. Объём работ

Входит: три экрана (живой звонок, анализ файла, паспорт), двуязычный интерфейс (русский и английский), Dockerfile.

Не входит: изменение API движка (если чего-то не хватает — запрос заказчику).

## 3. Функциональные требования

**FR-01. Экран «Звонок».**

- Список активных и последних сессий (`GET /v1/sessions`), выбор сессии; по умолчанию — самая свежая активная.
- Опрос событий раз в 250 мс (`GET /v1/sessions/{id}/events?since=k`).
- Большой индикатор вердикта: «Анализ…» (серый), «Норма» (зелёный), «Подозрение на синтез» (красный), «Нет решения» (жёлтый); время до вердикта в секундах речи.
- График накопленной статистики Λ по времени с горизонтальными линиями порогов A и B.
- Графики s1 (D1) и s2 (D2) по сегментам; для s2 — линия порога `z_{α/(2m)}`.
- Карточка «SMS абоненту» при событии `sms`.
- Для звонков бота — метка `live`/`spoof` из метаданных (только в режиме демонстрации, флаг `ui.show_labels`).

**FR-02. Экран «Анализ файла».**

- Загрузка файла (wav, flac, ogg, m4a, до 60 с), выбор канала (`clean`, `g711a`, `amrnb_12.2`, `amrnb_4.75`, `amrwb_12.65`).
- Вызов `POST /v1/analyze`; отображение тех же графиков, что на экране «Звонок».
- Раздел «Подробно о D2»: для каждого сегмента таблица проверок (check_id, δ, Z); график δ по проверкам с полосой эталона живой речи μ0 ± 3σ0 — наглядно видно, какие проверки «выбились».
- Файл после анализа не сохраняется ни панелью, ни движком.

**FR-03. Экран «Паспорт».** Паспорт детектора (`GET /v1/passport`) в читаемом виде: состав детекторов, канал, пороги, α̂ и α_up, β̂, время до вердикта, ограничения.

**FR-04. Язык интерфейса.** Переключатель RU/EN; все строки — в файле `ui/i18n.py`.

**FR-05. Настройки.** Адрес движка — переменная `VG_ENGINE_URL`. Панель работает при недоступном движке, показывая понятное сообщение.

**FR-06. Dockerfile.** `docker/Dockerfile.ui`, запуск `streamlit run src/voiceguard/ui/app.py`.

## 4. Нефункциональные требования

- Экран «Звонок» отображает новое событие не позже 0,5 с после его появления в движке.
- Интерфейс читается на проекторе: основной индикатор и графики видны при ширине окна 1280 px.

## 5. Критерии приёмки

- **AC-01.** С движком в тестовом режиме (ЧТЗ-10, FR-07) и звонком бота экран «Звонок» показывает рост Λ и смену вердикта на «Подозрение на синтез».
- **AC-02.** Анализ файла из фикстуры выводит графики и таблицу проверок D2.
- **AC-03.** Переключение языка меняет все подписи; непереведённых строк нет (тест по словарю `i18n`).
- **AC-04.** При остановленном движке панель не падает и показывает сообщение.
