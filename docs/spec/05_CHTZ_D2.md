# ЧТЗ-05. D2: предсказательный тест (метод диссертации)

Основание: общее ТЗ, разделы 7, 8, 11; диссертация С. А. Мирзояна, разделы 2.2–2.5; документ «Предсказательный тест синтетического голоса», разделы 2.3–2.4 и 2.7. Зависимости: ЧТЗ-04.

## 1. Цель

Реализовать двухрежимный предсказательный тест из диссертации как библиотеку, работающую на любых битовых последовательностях, и расширить её для голоса: эталон живой речи, стандартизованная статистика s₂, вариант B на джиттере основного тона.

Если заказчик передал исходный модуль `analysis.py` из комплекса «Проверка Криптостойкости», его логика переносится без изменений (побитовый и блочный режимы), а расширения добавляются поверх. Если модуль не передан, реализация выполняется по этому ЧТЗ.

## 2. Объём работ

Входит: побитовый и блочный предсказатели, 12 проверок, δ, режим совместимости с диссертацией, марковский хи-квадрат, построение и хранение эталона, статистика s₂, вариант B (биты и регрессия ρ), CLI.

Не входит: объединение с D1 и SPRT (ЧТЗ-08).

## 3. Функциональные требования

### 3.1 Предсказатели

**FR-01. Побитовый режим.** `voiceguard.d2.predictors.bit_delta(bits: np.ndarray, w: int, direction: str, cfg) -> tuple[float, int]` возвращает (δ, N_test).

- Для `direction="bwd"` последовательность разворачивается.
- Примеры: вход — w предыдущих бит (0/1 как float), цель — следующий бит.
- Разбиение: первые `train_frac` (0,8) примеров — обучение, остальные — тест; непрерывными участками, без перемешивания. Обучающая часть ограничивается `max_train` последними примерами перед границей.
- Модель: `sklearn.neural_network.MLPClassifier(hidden_layer_sizes=(w,), activation="relu", solver="adam", learning_rate_init=cfg.mlp_lr, random_state=cfg.seed, max_iter=cfg.max_iter)`; `max_iter` добавляется в конфигурацию (по умолчанию 200).
- `δ = p̂ − 0.5`, p̂ — доля верных предсказаний на тесте.

**FR-02. Блочный режим.** `block_delta(bits, w, direction, cfg) -> tuple[float, int]`.

- Последовательность режется на неперекрывающиеся блоки по w бит; примеры — пары (B_i, B_{i+1}).
- Модель: `MLPRegressor(hidden_layer_sizes=(w,), activation="relu", solver="adam", ...)` с многомерным выходом w; вход стандартизуется (`StandardScaler`, обученный только на обучающей части); выход порогуется по 0,5.
- Точность считается побитово по всем битам тестовых блоков; `δ_block = p̂ − 0.5`; N_test — число тестовых бит.
- В диссертации описан последовательный (авторегрессионный) вариант предсказания блока. Если передан `analysis.py`, повторить его поведение; иначе допускается многомерная регрессия, и выбор фиксируется в отчёте о сдаче.

**FR-03. Набор проверок.** `run_checks(bits, variant, cfg) -> dict[str, tuple[float, int]]` выполняет все сочетания `mode × w × direction` (по умолчанию 2 × 3 × 2 = 12) и возвращает словарь по `check_id` (формат — раздел 7 общего ТЗ). Проверки выполняются параллельно (`joblib`, число процессов из конфигурации). Проверка, для которой не хватает данных (менее 200 тестовых символов), возвращает `nan` и пропускается при расчёте статистики.

**FR-04. Режим совместимости с диссертацией.** `dissertation_verdict(bits, cfg) -> dict` воспроизводит исходную процедуру для ГПСЧ: обучающая выборка `T = min(⌊n/5⌋, 50)`, разбиение 80/20, `δ_общ = max δ` по 12 проверкам, порог

```
ε = z_{α/(2m)} / (2·√N_test),    m = 12
```

и вердикт «нарушение ТСБ», если `δ_общ > ε`. Режим нужен для проверки корректности порта на эталонных генераторах.

### 3.2 Хи-квадрат

**FR-05. Марковский критерий.** `voiceguard.d2.chi2.markov_test(bits, order: int, ref_probs: np.ndarray | None) -> tuple[float, float]` возвращает (χ², p-значение). Считаются переходы «контекст из `order` бит → следующий бит»:

```
χ² = Σ_c Σ_{b∈{0,1}} (O_{c,b} − N_c · π0(b|c))² / (N_c · π0(b|c)),    df = 2^order
```

При `ref_probs=None` эталон π0(b|c) = 0,5 (режим ГПСЧ). К каждой ячейке добавляется 1 (сглаживание, как в диссертации). Порядки по умолчанию — `chi2_orders: [2, 4, 6]` (добавить в конфигурацию). Результат записывается в `D2Result.chi2_p` и в s₂ не входит.

### 3.3 Эталон живой речи

**FR-06. Построение эталона.** `voiceguard.d2.reference.build(channel: str, variant: str, frames: str, cfg) -> Reference`.

- Данные: только часть `calib`, только `label == live` (ЧТЗ-02), после канала `channel` (ЧТЗ-03), сегменты по 1 с (ЧТЗ-04).
- Для каждой проверки j: `μ0_j = mean(δ_j)`, `σ0_j = std(δ_j, ddof=1)` по всем сегментам; дополнительно медиана и MAD (устойчивый вариант, выбирается флагом `reference.robust`).
- Сохраняются также теоретическая выборочная компонента `σ_samp = 1/(2·√mean(N_test))` и оценка междикторной компоненты `σ_spk = √max(σ0² − σ_samp², 0)`.
- Для марковского хи-квадрата сохраняются эталонные условные вероятности π0(b|c) для каждого порядка.
- Если сегментов меньше 500 или дикторов меньше 50, выдаётся предупреждение и флаг `underpowered: true`.

**FR-07. Хранение.** Эталоны сохраняются в `data/models/reference/{variant}_{frames}_{channel}.json` с полями: параметры конфигурации D2, число сегментов и дикторов, μ0, σ0, медиана, MAD, σ_samp, σ_spk по каждой проверке, π0 для хи-квадрата, хеш версии кода. `Reference.load(path)` проверяет совпадение параметров D2 с текущей конфигурацией и отказывает при расхождении.

### 3.4 Статистика и результат

**FR-08. Анализ сегмента.** `voiceguard.d2.analyze(segment: Segment, ref: Reference, cfg) -> D2Result`:

```
Z_j = (δ_j − μ0_j) / σ0_j,    s2 = max_j |Z_j|
```

Тест двусторонний. В `D2Result` заполняются все поля. Порог одиночного вердикта `z_{α/(2m)}` (при α = 0,01, m = 12 — 3,34) доступен как `voiceguard.d2.threshold(cfg, m)`, где m — число фактически выполненных проверок.

### 3.5 Вариант B

**FR-09. Биты джиттера.** Для варианта B используются символы `symbols_B` (ЧТЗ-04, FR-07) и те же предсказатели. Окна по умолчанию — `[4, 8, 16]` (параметр `d2.windows_B`), так как символов в 20–50 раз меньше, чем в варианте A. Анализ выполняется на накопленных периодах за `d2.segment_B_s` секунд (по умолчанию 5 с речи).

**FR-10. Регрессионный предсказатель.** `rho(d: np.ndarray, w: int, cfg) -> float`: `MLPRegressor(hidden=(w,))` предсказывает `d_{i+1}` по `d_{i−w+1..i}`, разбиение 80/20 непрерывное;

```
ρ = 1 − MSE_test / Var(d_test)
```

ρ входит в набор проверок варианта B как дополнительная проверка `B_rho_w{w}_fwd` со своим эталоном.

### 3.6 CLI

**FR-11.** Команды:

- `python -m voiceguard.d2 prng-check --gen {lfsr,mt,urandom} --n 100000` — режим совместимости (FR-04) на эталонных генераторах; LFSR и Mersenne Twister реализуются в `tests/prng_fixtures.py`;
- `python -m voiceguard.d2 build-ref --channel amrnb_12.2 --variant A --frames all`;
- `python -m voiceguard.d2 analyze --clip-id X --channel amrnb_12.2` — печать δ, Z, s₂, хи-квадрат по сегментам.

## 4. Нефункциональные требования

- 12 проверок варианта A на сегменте 1 с при 8 кГц: не более 2 с на 4 ядрах. Фактическое время по каждой проверке записывается в отчёт о сдаче; оно понадобится для выбора потокового режима в ЧТЗ-09.
- Полный детерминизм при фиксированном `seed`.

## 5. Критерии приёмки

- **AC-01.** Тест: на 200 последовательностях `os.urandom` по 100 000 бит режим совместимости даёт долю ложных «нарушений» не более 2α (α = 0,01).
- **AC-02.** Тест: на РСЛОС (полином степени 32) режим совместимости фиксирует нарушение; δ_общ того же порядка, что в диссертации (0,131), либо расхождение объяснено в отчёте.
- **AC-03.** Тест: на Mersenne Twister (`random.getrandbits`) режим совместимости воспроизводит вывод диссертации о нарушении при n = 100 000 или расхождение объяснено в отчёте.
- **AC-04.** Тест: на марковской цепи 1-го порядка с P(1|1) = 0,6 побитовый δ при w = 8 значимо больше 0, а марковский хи-квадрат порядка 2 даёт p < 0,001.
- **AC-05.** Тест: `build-ref` на фикстуре живой речи создаёт файл эталона; `Reference.load` отказывает при изменённом `d2.windows`.
- **AC-06.** Тест: `analyze` на сегменте из той же фикстуры даёт `s2` конечным числом и заполняет все поля `D2Result`.
- **AC-07.** Тест: `rho` на AR(1)-процессе с коэффициентом 0,8 даёт ρ в диапазоне 0,55–0,72; на белом шуме — |ρ| < 0,05.
- **AC-08.** Отчёт о сдаче содержит таблицу времени выполнения проверок (FR-03).

## 6. Указания агенту

- Формулы и параметры не менять без согласования: это метод из диссертации, результаты должны быть сопоставимы.
- Корректное значение квантиля: `scipy.stats.norm.isf(alpha / (2 * m))`; при α = 0,01 и m = 12 это ≈ 3,34.
