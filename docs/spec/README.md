## Как выдавать задание агенту

Шаблон сообщения:

```
Ты разрабатываешь проект VoiceGuard AM. Прочитай docs/spec/00_TZ_obshchee.md целиком,
затем выполни docs/spec/NN_....md.
Правила: работай только в границах этого ЧТЗ (раздел 10 общего ТЗ), не меняй types.py
и публичные интерфейсы других модулей. По завершении приложи отчёт о сдаче:
изменённые файлы, вывод make test и make lint, выполнение каждого критерия приёмки (AC),
принятые решения по неоднозначностям и открытые вопросы.
```

## Как принимать этап

1. Проверить отчёт о сдаче по каждому AC.
2. Самостоятельно запустить `make test` и `make lint`.
3. Для ЧТЗ-05: сверить результаты режима совместимости с таблицами диссертации.
4. После ЧТЗ-07: прочитать `report.md` и принять решение по воротам G1 (включать ли D2 в потоковый режим и какой вариант).

## Что понадобится от заказчика

- Исходный модуль `analysis.py` из комплекса «Проверка Криптостойкости» (для ЧТЗ-05; без него реализация идёт по описанию).
- Проверка армянского текста предупреждения носителем языка и, по возможности, запись фразы диктором (ЧТЗ-10).
- Решение по воротам G1 после ЧТЗ-07.
