# ЧТЗ-04. DSP: VAD, LPC-остаток, бинаризация, основной тон

Основание: общее ТЗ, разделы 7, 8, 11; документ «Предсказательный тест синтетического голоса», разделы 2.2 и 2.7. Зависимости: ЧТЗ-01.

## 1. Цель

Превратить звук в последовательности символов, которые анализирует D2:

- вариант A — биты LPC-остатка;
- вариант B — последовательность относительного джиттера периодов основного тона.

А также нарезать речь на сегменты по 1 с.

## 2. Объём работ

Входит: VAD и разметка вокализованных кадров, сегментация, LPC-анализ (собственная реализация Левинсона–Дарбина), обратная фильтрация с переносом состояния, бинаризация, извлечение периодов основного тона, джиттер, визуальная проверка.

Не входит: предсказатели и статистика (ЧТЗ-05).

## 3. Функциональные требования

**FR-01. VAD и сегментация.** `voiceguard.dsp.segment(clip: AudioClip, cfg) -> list[Segment]`.

- Кадры по 20 мс; VAD по `cfg.vad`; речевые кадры склеиваются в непрерывный поток и режутся на сегменты по `segment_s` (1 с). Остаток короче 0,5 с отбрасывается.
- `voiced_mask` — по кадрам: вокализованный, если кадр речевой и вероятность вокализации по `parselmouth` (pitch ≠ 0) истинна; допускается упрощённый критерий (нормированная автокорреляция на периоде 2,5–12,5 мс > 0,3), если он даёт согласие с parselmouth ≥ 90% на тестовой фикстуре.

**FR-02. LPC.** `voiceguard.dsp.lpc.levinson_durbin(r: np.ndarray, order: int) -> tuple[np.ndarray, float]` возвращает коэффициенты `a[1..p]` и ошибку предсказания. `lpc_frame(frame, order, window="hamming") -> np.ndarray`. Порядок: 10 при 8 кГц, 16 при 16 кГц (из конфигурации). К автокорреляции применяется регуляризация `r[0] *= 1 + 1e-9`, чтобы избежать вырождения на тишине.

**FR-03. Остаток.** `voiceguard.dsp.residual(samples, sr, cfg) -> np.ndarray`: покадровая обратная фильтрация

```
e[n] = x[n] − Σ_{k=1..p} a_k · x[n−k]
```

с коэффициентами текущего кадра; состояние фильтра (последние p отсчётов входа) переносится между кадрами.

**FR-04. Бинаризация (вариант A).** `voiceguard.dsp.binarize(e: np.ndarray, frame_len: int) -> np.ndarray[uint8]`: `b[n] = 1{e[n] > median(e в кадре)}`. Доля единиц по построению близка к 0,5 (отклонение только из-за равных медиане значений; такие отсчёты получают 0).

**FR-05. Разделение по классам кадров.** `symbols_A(segment, cfg, frames: Literal["all","voiced","unvoiced"]) -> np.ndarray[uint8]` возвращает биты только выбранных кадров, склеенные подряд.

**FR-06. Основной тон (вариант B).** `voiceguard.dsp.pitch.periods(clip_or_segment, sr) -> np.ndarray` — последовательность длительностей периодов T_i (в отсчётах, дробные) на вокализованных участках. Метод: отметки периодов через `parselmouth` (`To PointProcess (periodic, cc)`), T_i — разности соседних отметок. Периоды через границу невокализованного участка не считаются.

**FR-07. Джиттер.** `jitter_sequence(T: np.ndarray) -> np.ndarray` возвращает `d_i = (T_{i+1} − T_i) / mean(T)`; `symbols_B(T) -> np.ndarray[uint8]` возвращает `c_i = 1{d_i > 0}`.

**FR-08. Визуальная проверка.** `python -m voiceguard.dsp inspect --clip-id X --channel amrnb_12.2` сохраняет в `reports/inspect/X.png` осциллограмму, остаток, разметку VAD и вокализации, контур основного тона.

## 4. Нефункциональные требования

- Обработка 1 с звука при 8 кГц (VAD + LPC + остаток + бинаризация) — не более 20 мс на одном ядре.
- Извлечение периодов для 1 с — не более 50 мс.

## 5. Критерии приёмки

- **AC-01.** Тест: `levinson_durbin` совпадает с `librosa.lpc` (или с решением системы Юла–Уокера через `scipy.linalg.solve_toeplitz`) с точностью 1e-6.
- **AC-02.** Тест: для AR(2)-процесса с известными коэффициентами оценка при p = 2 отличается от истинных не более чем на 0,05 на 10 000 отсчётов.
- **AC-03.** Тест: остаток белого шума, пропущенного через известный AR-фильтр, имеет автокорреляцию на лагах 1…10 по модулю < 0,05.
- **AC-04.** Тест: доля единиц после `binarize` на речи — 0,49…0,51.
- **AC-05.** Тест: на синтетическом «гласном» сигнале (импульсная последовательность 125 Гц через формантный фильтр) средний период = 64 отсчёта при 8 кГц ± 1.
- **AC-06.** Тест: сегментация 10 с речи с паузами даёт сегменты ровно по 1 с речевого материала.
- **AC-07.** `inspect` формирует изображение для клипа из фикстуры.
